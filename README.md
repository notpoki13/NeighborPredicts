# Hello Neighbor Visit Predictor

Static GitHub Pages website for tracking Hello Neighbor Roblox visits and predicting milestone dates.

## Setup
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select your main branch and `/ (root)`.
5. Open the GitHub Pages URL.

The site starts at 497 visits and a 500 goal. It stores snapshots in the browser's localStorage, calculates average visits/day, updates predictions when new snapshots are added, and automatically advances a reached milestone by 100.
