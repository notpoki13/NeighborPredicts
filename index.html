How it works

  1. A GitHub Action checks Roblox's public game stats automatically.
  2. If the visit count changed, it records a new timestamped snapshot.
  3. The site reads the saved history and recalculates visits/day.
  4. When a milestone is reached, the dashboard advances by 100.

The dashboard itself is static; GitHub Actions performs the automatic polling so no Roblox login or secret is placed in the website.
